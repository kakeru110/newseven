# 民泊ダッシュボード

民泊（住宅宿泊事業）の **売上・稼働率・予約・経費・タスク** を 1 画面で確認できる
ダッシュボードです。ビルド不要・ライブラリ不要で、`index.html` をブラウザで開くだけで動きます。

物件別・月別の実績は、`data/data.js` に入力した予約データからすべて自動計算されます。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く（ローカルサーバー不要）
2. 右上の **対象月 / 物件** を切り替えると、全カードが連動して再計算されます
3. グラフの棒・点をクリックすると、その月の表示に切り替わります

いまは動作確認用の **サンプルデータ** が入っています。

## データの入れ替え（ここだけ触ればOK）

編集するのは **`data/data.js` の 1 ファイルだけ** です。HTML / CSS / JS は触りません。

```bash
cp data/data.template.js data/data.js   # 空のテンプレートから始める場合
```

| 項目 | 内容 |
| --- | --- |
| `settings` | タイトル・目標稼働率・目標月商・初期表示月など |
| `properties` | 物件マスタ（`id` を予約・経費から参照します） |
| `bookings` | 予約明細 ← **売上・稼働率・ADR・RevPAR はここから計算** |
| `expenses` | 経費（月次・物件別）← 営業利益を計算 |
| `reviews` | レビュー評価（`scale: 10` で 10 点満点にも対応） |
| `tasks` | 清掃以外のタスク（清掃はチェックアウトから自動表示） |

各項目の書き方は `data/data.template.js` のコメントに記載しています。
実データに入れ替えたら `settings.demo` を `false` にすると「サンプルデータ」バッジが消えます。

### 入力例

```js
properties: [
  { "id": "house1", "name": "浅草リバーサイド 2LDK", "area": "東京都台東区",
    "capacity": 6, "cleaningFee": 8000, "listedFrom": "2026-01-01" },
],
bookings: [
  { "id": "BK0001", "propertyId": "house1", "channel": "Airbnb", "guestName": "山田 太郎",
    "guests": 2, "checkIn": "2026-01-10", "checkOut": "2026-01-13", "amount": 68000 },
],
```

## 計算ルール

| 指標 | 定義 |
| --- | --- |
| 売上 | 予約の受取総額を**宿泊数で日割り**し、各月へ配分 |
| 稼働率 | 宿泊した日数 ÷ 販売可能日数（`listedFrom` 以降の日数） |
| ADR | 売上 ÷ 宿泊日数（1 泊あたりの平均単価） |
| RevPAR | 売上 ÷ 販売可能日数（空室も含めた 1 室あたり売上） |
| 予約件数 | その月に**チェックインした**予約の件数 |
| 営業利益 | 売上 − 経費（利益率＝営業利益 ÷ 売上） |

宿泊数は「退室日 − 入室日」で数え、チェックアウト日は宿泊にカウントしません。

## 画面構成

- **KPI** — 売上（目標達成メーター付き）／稼働率／ADR／RevPAR／予約件数／営業利益／レビュー評価。各タイルに前月比と直近 12 ヶ月のスパークライン
- **月次売上の推移 / 稼働率の推移** — 直近 12 ヶ月。選択中の月を強調、目標稼働率のラインを表示
- **稼働カレンダー** — 物件 × 日のガント表示。バーにカーソルを合わせると予約詳細
- **物件別の稼働率 / 予約経路別の売上 / 経費の内訳** — 選択中の月の内訳
- **物件一覧** — 稼働率・売上・ADR・評価・次回チェックイン・状態
- **直近の予定 / タスク** — 今日以降のチェックイン・チェックアウト（清掃）とタスク（クリックで完了切替）
- **月次サマリー（表）** — グラフと同じ数値の表ビュー

## ファイル構成

```
index.html               画面の枠組み
assets/styles.css        スタイル（ライト / ダーク両対応）
assets/app.js            集計とグラフ描画（依存ライブラリなし）
data/data.js             ★ ここにデータを入力
data/data.template.js    空の入力テンプレート
```

## メモ

- ライト / ダークは OS 設定に追従し、右上のボタンで手動切替もできます（選択はブラウザに保存）
- タスクの完了状態はブラウザの `localStorage` に保存されます（端末ごと）
- 画面幅に合わせてレイアウトとグラフが再描画されます（スマートフォン表示にも対応）
